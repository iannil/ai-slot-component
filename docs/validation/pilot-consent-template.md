# CMS 试点授权模板

本模板由站点负责人在客户侧安装前填写和确认。任何字段未明确时，不启动客户侧安装。默认不采集客户真实业务内容，仅记录时间与匿名错误码。

| 字段 | 待填写内容 |
| --- | --- |
| 负责人 | 姓名、角色与确认日期：________ |
| 站点 / slot | 站点域名、非关键页面及授权槽位 ID：________ |
| 允许只读的源 | 具体 CMS 端点、字段及访问方式：________ |
| 允许动作 | 接入、预览、提交审核、发布、撤回等逐项列出；未列出即不授权：________ |
| 发布窗口 | 允许发布时间、时区、审批人：________ |
| 域名 / CSP 限制 | 可请求的域名及相关 CSP 约束：________ |
| 数据记录范围 | 用时、匿名错误码及保留期限；默认不采真实业务内容：________ |
| 撤回责任人 | 姓名、联系方式、撤回操作与响应窗口：________ |

负责人确认：________　日期：________
