运营控制台

运营/开发者在这里改卖点方向（提示词）或发布内容更新，失效推送让所有打开的页面原地更新。建议与任意行业页并排打开：左边控制台发布，右边页面即刻变化。

提示：每页底部另有一个「推荐」槽位，它背后的 AI 服务被故意置为故障——页面照常显示静态推荐内容， 这就是静默兜底。构建期预生成可执行 node prewarm.mjs； 调整卖点方向可 POST /admin/prompt?slot=<槽位名>&prompt=<新提示词>， 模拟数据源变更可 POST /admin/publish?slot=<槽位名>。
